# Coletor Web
## Sistema de Coleta de Dados Web da Linear Sistema
## A Aplicação Web responsiva funciona em qualquer dispositivo que possua um navegador e que tenha acesso ao servidor onde esta instalado o serviço;
## O usuário irá fazer a coleta usando a camera do dispositivo e posteriormente, fazer o download do arquivo coletado e importar para o SGLinear (ERP).
