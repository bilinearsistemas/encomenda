# Gestão de Encomendas
## Sistema para gestão de encomendas realizadas no SGLinear
## Ele será responsavel por adicionar status de modo a parametrizar e organizar a demanda na produção
## Também é possível visualizar imagens adicionadas a encomenda como por exemplo a foto a ser adicionada pela confeitaria em um bolo.
## Além de outro fatores como regra de horarios, embalagens...
